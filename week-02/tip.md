# Tips for this week

This week was focused on turning our early planning into a more practical working setup for the project. After the initial discussions and wireframing work from the previous week, I started concentrating on how the group would actually organise development in a way that was manageable and efficient. A key part of my contribution this week was completing the Git and GitHub recipes work, which helped strengthen my understanding of version control and gave me a clearer idea of how to structure collaboration within the team.
Using that understanding, I helped set up the group GitHub repository and added the team members so we could begin working in a shared development space. I saw this as an important step because without a properly organised repository, it would have been much harder to coordinate work, track progress, and avoid confusion once multiple people started contributing code. By getting this in place early, I helped establish a more professional workflow for the team and gave us a central place to manage the project.
Alongside the repository setup, I also helped assign tasks to different group members based on the work that needed doing at that stage. This linked back to the wireframes and the direction we had already agreed as a team. Rather than staying at the planning stage for too long, I wanted us to begin converting our agreed design ideas into actual development work. Because of that, I also started coding parts of the application based on the confirmed wireframe, which helped move the project from concept into implementation.
This week also helped me build a better understanding of the client requirements. As we moved from sketches into practical setup and early coding, it became clearer which features would need to be prioritised and how the application would need to function in a real healthcare environment. I began to see that the project was not only about making something that looked good, but also about making sure it was usable, structured properly, and realistic for the client’s needs.
Overall, my work this week helped give the team a stronger technical and organisational foundation. Setting up the repository, allocating tasks, and beginning implementation all contributed to a more focused start to development. Looking back, this week was important because it moved us beyond ideas and into a proper working process, which made later collaboration much easier and more effective.
This fits the brief better because it shows your actions, your contribution to team progress, and a clearer sense of organisation and involvement, which is what the first-class band is looking for in the diary.
